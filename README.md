## Tech Stack
* HTML5
* CSS3
* JavaScript

## Fitur Utama
* Tampilan antarmuka website BNCC.
* Penataan gaya dan tata letak responsif via CSS.
* Interaktivitas website menggunakan JavaScript.

## Contribution
* **Anggota 1 (Project Initiator - Hugo):** Inisiasi repository, setup file awal `index.html`, review & merge Pull Request.
* **Anggota 2 (Styling Engineer - Firdaus):** Pengembangan stylesheet dan penataan tampilan website (`style.css`).
* **Anggota 3 (Script Engineer - Kamu):** Pengembangan logika interaktivitas (`script.js`) dan perbaikan sintaks CSS.

## What I Learned
* Memahami alur kerja kolaborasi Git & GitHub (Branching, Pull Request, Code Review, dan Merge).
* Menangani dan menyelesaikan konflik kode (Merge Conflict) secara bersama.

## Feature Improvement
* Menambahkan animasi interaktif yang lebih kompleks.
* Mengoptimalkan performa halaman dan responsivitas pada perangkat mobile.
